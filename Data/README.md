# İşlem girdileri

Yeni işlem öncesinde bu klasöre verilerinizi koyun:

- Önceki gün SP3
- Ölçüm günü SP3
- Sonraki gün SP3
- Ölçüm gününün RINEX 3 gözlem dosyası (.rnx veya .obs)
- PPP-AR için ayrıca seçilen SDBS/DCM yöntemine uygun normalize saat/bias JSON ürünü
- İsteğe bağlı: IONEX küresel iyonosfer haritası (`*.INX`, `*.INX.gz`) ve istasyonun SINEX_TRO troposfer ürünü (`*.TRO`, `*.TRO.gz`, `*.zpd`). Tek bir tane varsa otomatik seçilir.

Arayüzde “Data klasöründeki verileri seç” düğmesini kullanın. Birden çok veri seti varsa Seç düğmeleriyle dosyaları belirleyin. Alt klasörler desteklenir. Sonuçlar seçtiğiniz çıktı klasörüne yazılır. Program buradaki dosyaları otomatik silmez.
